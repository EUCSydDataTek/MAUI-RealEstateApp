# Compass Image Placeholder

For the compass functionality to work, you need to add a compass.png image to the Resources/Images folder.

You can:
1. Download a compass image from the internet
2. Create a simple compass design
3. Use the blue compass arrow design as shown in your mockup

The image should be a simple compass design with:
- Clear directional arrow pointing upward (representing North)
- Good contrast for visibility
- Transparent background (PNG format)
- Size: 200x200 pixels or larger

Place the image at: Resources/Images/compass.png
